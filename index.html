Deployment & Database Setup

This single HTML file contains the complete browser app and embedded deployment sources. Supabase database policies and Edge Functions still run on Supabase servers; HTML alone cannot securely execute payment secrets or webhooks.

Run the SQL in Supabase SQL Editor on a new project, then assign your own authenticated UUID to the admins table from the SQL Editor. Review the SQL before applying it to an existing project.

Deploy each downloaded index.ts into a Supabase Edge Function named football-fixtures, pesajet-checkout, or pesajet-webhook. Configure provider secrets on the server, never in this HTML.
